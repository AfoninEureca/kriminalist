# Сезон 6: штаб «Меридиан»

Новый интерфейс «операционный штаб» только для сезона 6. Сезоны 1–5 остаются как есть.

- `hq.html` — готовая игра (один файл): эпизоды 41–48: «Общая учётная запись», «Терминал без хозяина», «Регламент как щит», «Клиент всегда прав», «Релиз по пятницам», «Схема, которой нет», «Слишком много „нет“», «Совет, которому поверили» (финал сезона).
- `src/engine.html` — общий движок и интерфейс.
- `src/prelude.js` — помощники для сборки данных; `src/ep41.js`…`src/ep48.js` — данные эпизодов: гипотезы, меры, досье, диалоги, развилки.
- `src/build.py` — сборка: запускать из папки, где лежит `hq/` с этими файлами (`hq/engine.html`, `hq/epNN.js`), результат `hq_all.html`.

Восемь руководителей «Меридиана»: Беляев, Ермакова, Хасанов, Орлов, Мельник, Воронов, Седова, Ковалёв. Доверие каждого переходит из эпизода в эпизод (в браузере игрока). Режим «мой отдел» выбирается в начале эпизода.
