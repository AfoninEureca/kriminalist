# Telegram-бот и мини-приложение · @CyberSherlock404bot

Пакет из двух частей:

| Папка | Что это | Где живёт |
|---|---|---|
| `docs/` | Игра: каталог и сцены 2–40 как мини-приложение Telegram и обычный сайт | GitHub Pages (Settings → Pages → ветка `main`, папка `/docs`) |
| `bot/` | Бот на Python: кнопка «Играть», протоколы, истории игроков, модерация, баллы, рейтинг, карточки | компьютер или сервер, где запущен `python bot.py` |

## 1. Выложить игру (2 минуты)

Игра уже лежит в папке `docs/` этого репозитория.

1. Settings → Pages → Source: *Deploy from a branch*, ветка `main`, папка `/docs` → Save.
2. Через минуту игра откроется по адресу `https://afonineureca.github.io/kriminalist/`. Это и есть `WEBAPP_URL` (без `/` в конце).

Вне Telegram страницы работают как обычные: файл `tg.js` включается только внутри Telegram.

## 2. Настроить бота в @BotFather

1. `/mybots` → @CyberSherlock404bot → *API Token* — скопируйте токен. **Никому его не пересылайте**, в том числе в чат с Claude.
2. *Bot Settings → Group Privacy → Turn off* — нужно, только если модераторы работают в группе.
3. По желанию: *Edit Bot → Edit Description* — «Учебная игра про цифровую криминалистику. Играйте сцены, присылайте свои истории, получайте баллы».

## 3. Модераторы

1. Создайте группу «Контур · модерация», добавьте туда бота и модераторов.
2. Напишите в группе `/myid` — бот ответит id группы (начинается с `-100`). Это `MOD_CHAT_ID`.
3. Каждый модератор пишет боту в личку `/myid` — это его id для `ADMIN_IDS`.

Можно и без группы: укажите в `MOD_CHAT_ID` свой личный id.

## 4. Запустить бота

```bash
cd bot
python3 -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env      # впишите BOT_TOKEN, WEBAPP_URL, MOD_CHAT_ID, ADMIN_IDS
python bot.py
```

Бот работает, пока запущена программа. Для постоянной работы подойдёт любой недорогой VPS (1 ядро, 512 МБ) с `systemd` или `screen`. База — один файл `kontur.db` рядом с ботом, его стоит копировать раз в неделю.

## Что видит игрок

Кнопки под полем ввода: **🎮 Играть** · **✍️ Прислать историю** · **🏆 Мои баллы** · **📄 Карточки** · **❓ Правила**.

* **Игра.** «🎮 Играть» открывает каталог сцен внутри Telegram. Тема (светлая/тёмная) берётся из Telegram, кнопка «Назад» закрывает карточку или возвращает в каталог. Когда дело закрыто, внизу появляется кнопка **«Сдать протокол в бот»**: бот сохраняет протокол и начисляет баллы за лучший результат по сцене (1★ = 1 балл).
  Сдать протокол можно, только если игра открыта кнопкой «🎮 Играть» под полем ввода — так устроен Telegram. Если игру открыли по ссылке, протокол копируется, и его можно прислать сообщением.
* **История для разбора** — пять шагов: откуда история → название → что произошло (от 150 знаков) → какое слабое место → источник, скриншоты или документы (до 5) → подтверждение. Бот не примет текст с номером карты, телефоном, почтой или паролем и попросит заменить их словами. Не больше 3 историй в день.
* **Баллы и звания:** Стажёр центра (0) → Младший сыщик (10) → Сыщик (30) → Старший сыщик (60) → Эксперт центра (120). `/top` — рейтинг, `/mystories` — статусы своих историй.

## Баллы за истории

| Решение модератора | Баллы автору | Что видит автор |
|---|---|---|
| ✅ Правдоподобно | +10 | «История признана правдоподобной» |
| 🎬 Создан сценарий | +30 (и +10, если не была отмечена правдоподобной) | «По вашей истории создан новый сценарий — сцена N» |
| ❓ Уточнить | — | вопрос модератора; ответ автора приходит модераторам с историей |
| ❌ Отклонить | — | вежливое письмо с благодарностью |

Команды модератора: `/queue` — очередь, `/show N` — история с кнопками, `/scenario N S` — по истории N создана сцена S, `/award ID БАЛЛЫ причина` — ручная поправка, `/stats` — сводка.

Изменить число баллов или лимит: константы `PTS_PLAUSIBLE`, `PTS_SCENARIO`, `STORIES_PER_DAY`, `RANKS` в начале `bot.py`.

## Новая сцена

1. Положите `scene-41.html` в `docs/`. Перед `</body>` добавьте три строки, как в остальных сценах:
   ```html
   <script src="https://telegram.org/js/telegram-web-app.js"></script>
   <script>window.KONTUR_SCENE=41;</script>
   <script src="tg.js"></script>
   ```
2. Добавьте карточку сцены в `index.html`, а название — в словарь `SCENES` в `bot.py`.
3. PDF карточек положите в `bot/cards/`. Проверьте, что номер сцены есть в `SCENES` в `bot.py`.

## Что бот не принимает

Кроме личных данных бот отклоняет тексты с рабочим содержимым атак: блоки кода, строки команд, известные инструменты атак, шестнадцатеричные дампы, пошаговые «инструкции». Игрок получает сообщение «опишите словами, что заметили и как защититься». Правила проверки — в `find_operational` (`bot.py`); подробности и причины — в [CVP-AUDIT.md](CVP-AUDIT.md). Модератор отклоняет и то, что фильтр пропустил.

## Личные данные

Бот хранит id Telegram, имя, протоколы и тексты историй. Не храните в историях персональные данные — бот это проверяет, но модератору тоже стоит смотреть. Если проект выйдет за пределы учебной группы, нужна политика обработки персональных данных (в России — по 152‑ФЗ); ссылку на неё можно добавить в `RULES_TEXT`.

## Сезоны 6–10 (штаб «Меридиан»)
Эпизоды 41–80 открываются из каталога игры (блок «Штаб „Меридиан“», файл `docs/hq.html`). Внутри Telegram работает кнопка «Назад» и «Сдать протокол в бот» после закрытого эпизода: бот сохраняет результат и начисляет баллы за звёзды, как в сценах 2–40. При обновлении игры файл `docs/hq.html` — копия `materials/season-6/hq.html` с двумя дополнительными строками перед `</body>` (скрипт Telegram и `tg-hq.js`). Бот после обновления нужно перезапустить: `python bot.py`.
